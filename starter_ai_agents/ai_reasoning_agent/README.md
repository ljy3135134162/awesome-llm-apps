## AI 推理 Agent

AI Reasoning Agent 利用先进的 AI 模型提供推理与决策能力。该 Agent 通过处理输入信息并生成结构化结果，帮助用户完成各种分析类任务。

### 功能特性
- **高级推理**：使用 Ollama 模型处理复杂推理任务
- **交互式 Playground**：提供易于使用的交互界面
- **Markdown 支持**：以 Markdown 格式输出结果，便于阅读和分享
- **可自定义 Agent**：可以方便地针对不同推理场景调整配置

### 如何开始

1. **克隆仓库**：

```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd starter_ai_agents/ai_reasoning_agent
```

2. **安装所需依赖**：

#### 本地 AI 推理 Agent

```bash
pip install -r requirements.txt
```

3. **运行应用**：

```bash
python local_ai_reasoning_agent.py
```

### 使用 Agent

1. **打开 Playground**：
   - 打开程序提供的 URL 进入交互式 Playground。
   - 可以在 Playground 中输入问题并获得结构化推理结果。

2. **输入查询**：
   - 在输入框中填写问题或分析任务。
   - Agent 会处理输入，并返回详细的推理与分析结果。

3. **查看结果**：
   - 结果以 Markdown 格式显示。
   - 可以方便地复制和分享输出内容。

### 功能详解

- **推理能力**：
  - 支持多种分析任务
  - 输出清晰、结构化的结果
  - 支持 Markdown，便于阅读和分享

- **交互界面**：
  - 提供易用的 Playground
  - 实时处理输入并生成结果
  - 可通过配置项调整 Agent 行为
